# 🌦️ MeteoCard

**Seu espaço para acompanhar o tempo e explorar a meteorologia!**

O MeteoCard é um projeto de site meteorológico criado para consultar informações sobre o clima de forma simples e visual.

## ✨ Funcionalidades

- 🌡️ Consulta de informações meteorológicas.
- 🌧️ Dados do tempo obtidos pela API Open-Meteo.
- 📊 Gráficos para visualizar informações meteorológicas.
- 🔎 Busca de cidades para consultar o clima.
- 💻 Interface simples e intuitiva.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- API [Open-Meteo](<https://open-meteo.com/>)

## 🚀 Como acessar

O MeteoCard poderá ser acessado diretamente pelo navegador quando a publicação pelo GitHub Pages estiver configurada.

## 📌 Sobre o projeto

Este projeto está em desenvolvimento e poderá receber novas funcionalidades, melhorias visuais e ferramentas meteorológicas no futuro.
